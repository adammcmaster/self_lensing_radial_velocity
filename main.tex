\section{Methods}

Aiming to figure out what RV accuracy and observing cadence is required to confirm which self-lensing systems, in terms of their physical properties.

For short period systems, we can just observe them a bunch of times, recover their orbital period with a periodogram, and fold the RV curve. For these systems we need to know how frequently we'd need to observe them over, say, 1 year to be able to recover the period.

For longer periods we won't see any complete orbits so we'd need to know which systems it would be possible to fit as a function of length of observing campaign.

Ideally we want this to work whether or not we know the orbital period beforehand, so we can have a single pipeline that recovers binary systems regardless.

There must be packages out there for recovering single lined spectroscopic binaries. That's all we need to do. No need to reinvent the wheel.

So in this paper we should:

\begin{enumerate}
    \item Generate a library of pristine RV curves for a range of SL systems. \textbf{Which systems to generate? A grid of possible values, or use Greg's results?} I'd lean towards not using Greg's results and just fully covering the parameter space.
    \item Sample the pristine systems and add noise to simulate various observing cadences with various RV accuracies.
    \item Run Lomb-Scargle on each RV curve and see if the correct period comes out.
    \item Feed all of those RV curves into a well known package for fitting SB1 orbits. Record whether the correct orbital period was recovered. \texttt{radvel} looks ideal: \url{https://radvel.readthedocs.io/en/latest/quickstartcli.html}
    \item Plot the orbital period correctness as a function of $M_\text{total}$, $P_\text{orb}$, RV accuracy, and observing cadence. If we can somehow visualise that in an understandable way on one plot, then great.
\end{enumerate}

At the end we can hopefully say what RV accuracy we need, what observing cadence we need, and determine which systems we can confirm with Lomb-Scargle and which would need a full radvel fit.
